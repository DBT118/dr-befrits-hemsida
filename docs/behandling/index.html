Behandling

Som läkare ser jag till helheten av kropp och själ. Jag hjälper dig att förstå dina besvär och hitta en förklaringsmodell som tar hänsyn till din individuella historia och livssituation. Utifrån dina behov kan jag rekommendera en lämplig behandling med målet att förbättra ditt välmående.

Behandlingen kan exempelvis innefatta:

  • Psykoterapi med inriktning KBT

    Kognitiv beteendeterapi (KBT) är ett samarbete där både du och jag är aktiva. Tillsammans utforskar vi det du upplever som problematiskt och arbetar för att öka förståelsen för dina tankar, känslor och beteenden. Arbetet kan vara både utmanande och krävande, men ger dig möjlighet att utveckla nya förhållningssätt och strategier för att må bättre.

  • Psykiatrisk utredning

    Utredning för att undersöka och vid behov fastställa psykiatriska diagnoser, samt identifiera lämpliga behandlingsalternativ.

  • Läkemedelsbehandling

    Bedömning och behandling med läkemedel vid psykiatriska tillstånd, utifrån dina individuella behov och förutsättningar.

  • Kompletterande laboratorieprover

    Vid behov kan laboratorieprover tas för att undersöka kroppsliga faktorer som kan påverka ditt psykiska mående.

  • Samverkan med andra vårdgivare

    När det behövs samarbetar jag med andra vårdgivare för att säkerställa en så heltäckande vård som möjligt. Det kan exempelvis handla om läkare med somatisk inriktning, dietister eller fysioterapeuter.
